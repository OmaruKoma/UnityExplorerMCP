UnityExplorerMCP
功能安装工具发布English
Runtime MCP · 不是 Editor MCP

让 AI Agent 直接检视运行中的 Unity 游戏

UnityExplorerMCP 将 Model Context Protocol 服务连接到游戏进程。遍历场景、探索类型、读取和写入字段、调用方法、在进程内执行 C#、查看 BepInEx 日志。支持 IL2CPP 与 Mono，可从任意 MCP 客户端使用。

下载 Release查看安装指南GitHub 源码完整中文文档

使用示例

Agent 发起一组工具调用，直接检查游戏运行时状态；无需打开 Editor、重新构建或反复重启。

> “商店按钮点了没反应。找到商店控制器，看它需要什么，然后按 UI 的方式调用它。”

unity_capabilities          {}                                  → 后端、会话、限额
unity_find_objects_of_type  { "type": "Game.ShopController" }    → 句柄
unity_inspect               { "handle": "ShopController#7:-33814" }
unity_search_members       { "name_contains": "Open" }
unity_get_field             { "handle": "ShopController#7:-33814", "field": "_isReady" }
unity_invoke_method         { "handle": "ShopController#7:-33814", "method": "Open" }
unity_tail_log              { "lines": 50 }                      → 查看后续日志

功能

面向 Agent 的运行时接口，提供有边界的输出、明确的限额和真实的能力报告。

运行时检视

读取实际运行进程中的 GameObject、组件、字段、属性与方法。

反射与类型搜索

跨已加载程序集发现类型、搜索成员并查找活实例。

读取、写入与调用

访问实例和静态字段、属性；调用包括 out/ref 参数的方法。

游戏内执行 C#

内置 Mono.CSharp 执行引擎，不依赖额外 UI。

Session 感知句柄

句柄绑定会话；过期时以 STALE_HANDLE 快速失败，避免操作错误对象。

适合 Agent 的输出

支持分页、带 SHA-256 的截断、成员数量限制和结构化错误。

Harmony Hook 清单

只读列出已 patch 的方法及其 patch 所有者。

日志查看

读取 BepInEx/LogOutput.log，不锁定游戏文件；游戏关闭时也可查看。

安装

需要安装 BepInEx 的 Unity 游戏；Server 需要 Node.js 18+。只有自行编译桥接 DLL 时才需要 .NET SDK。

1. 安装游戏内桥接插件

从 Releases 下载与加载器匹配的压缩包，解压到 <GAME_ROOT>/BepInEx/plugins/。桥接 DLL 和 mcs.dll 必须放在同一目录。

2. 启动 MCP Server

下载 Server 源码或克隆仓库，在 mcp-server 目录安装依赖并运行：

npm ci
npm run build
node dist/server.js

3. 配置 MCP 客户端

将客户端配置中的命令指向 Server 的 dist/server.js，并设置桥接地址：

"UNITY_BRIDGE_URL":
  "http://127.0.0.1:12345"

4. 验证连接

让 Agent 调用 unity_capabilities。收到后端、会话和工具信息，就说明桥接、Server 与客户端已连通。

支持的桥接包：IL2CPP / BepInEx 6、Mono / BepInEx 6、Mono / BepInEx 5。详细步骤和 Claude Desktop、Cursor、OpenCode 配置示例见中文 README。

24 个 MCP 工具

每次会话先调用 unity_capabilities，获取当前游戏后端、会话、可用工具和限额。

类别工具
发现unity_capabilities · unity_ping · unity_scene_info · unity_list_assemblies

兼容性

Mono · BepInEx 5已实测Unity 2019.4，BepInEx 5.4
Mono · BepInEx 6仅编译验证源码一致，尚无游戏内运行测试

安全说明

桥接服务仅监听本机 127.0.0.1，并会执行 Agent 发送的任意 C#。请将其视为已连接的调试器，仅在自己的机器和游戏上使用。set_* 与 invoke_* 会修改运行时状态，操作前先检查目标。
